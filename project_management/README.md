# Управление проектом IRSbese

- `source/IRSbese_исходная_сводка.xlsx` — исходный файл, полученный от пользователя; не изменялся.
- `IRSbese_актуальная_сводка.xlsx` — обновлённая версия с результатами по 115 задачам, заметками, статусами этапов и уточнённым паспортом проекта.
- `TASK_TRACEABILITY.md` — текстовая трассировка всех 115 задач и артефактов.

Статус `Готово` присвоен задачам, для которых в архиве есть код, документ, макет, тест-кейс или иной заявленный результат. `На проверке` оставлен для задач, которым нужен запуск приложения, браузерный прогон или ручная проверка. `Заблокировано` — для задач, требующих внешних ключей, репозитория или записи реального видео.
