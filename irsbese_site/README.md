# IRSbese — каркас интернет-магазина

Учебный каркас маркетплейса на Python и Flask по брендбуку IRSbese.

## 1. Запуск

1. Установить Python 3.10 или новее.
2. Открыть терминал в папке проекта.
3. Создать виртуальное окружение:
   `python -m venv venv`
4. Активировать окружение:
   Windows: `venv\\Scripts\\activate`
   macOS/Linux: `source venv/bin/activate`
5. Установить зависимости:
   `pip install -r requirements.txt`
6. Запустить:
   `python run.py`
7. Открыть в браузере: `http://127.0.0.1:5000`

## 2. Структура проекта

- `run.py` — запуск приложения.
- `config.py` — настройки.
- `app/__init__.py` — создание Flask-приложения и подключение маршрутов.
- `app/data.py` — временные демонстрационные товары.
- `app/routes/` — обработчики страниц и URL.
- `app/templates/base.html` — общий шаблон.
- `app/templates/partials/` — повторно используемые части интерфейса.
- `app/templates/pages/` — отдельные страницы сайта.
- `app/static/css/tokens.css` — цвета и базовые дизайн-токены.
- `app/static/css/base.css` — общие стили.
- `app/static/css/components.css` — стили компонентов.
- `app/static/js/main.js` — клиентский JavaScript.

## 3. Карта частей кода

- ЧАСТЬ 1 — запуск и конфигурация (`run.py`, `config.py`).
- ЧАСТЬ 2 — создание приложения (`app/__init__.py`).
- ЧАСТЬ 3 — демонстрационные данные (`app/data.py`).
- ЧАСТЬ 4 — общий HTML-шаблон и повторяемые блоки (`base.html`, `partials/`).
- ЧАСТЬ 5 — маршруты и страницы (`app/routes/`, `pages/`).
- ЧАСТЬ 6 — визуальная система по брендбуку (`static/css/`).
- ЧАСТЬ 7 — клиентская логика (`static/js/`).

## 4. Что уже есть

- Главная страница с поиском и двумя сценариями: «Покупаю» и «Продаю».
- Каталог с простым поиском по названию и категории.
- Карточка товара.
- Макеты корзины и оформления заказа.
- Страницы личного кабинета, входа и регистрации.
- Кабинет продавца и форма добавления товара.
- Страницы ошибок 404 и 500.
- Адаптивные стили для телефона и компьютера.

## 5. Что разработчику нужно реализовать

Это именно каркас, а не готовый интернет-магазин. Пока не подключены:
- база данных и модели;
- регистрация, авторизация и безопасное хранение паролей;
- сохранение корзины и заказов;
- загрузка фотографий и сохранение товаров продавца;
- реальная оплата ЮKassa;
- персональные рекомендации;
- полноценная обработка ошибок и тестирование.

Эти функции остаются задачами разработчика и других участников команды. Демонстрационные кнопки и формы не выполняют реальные операции.
