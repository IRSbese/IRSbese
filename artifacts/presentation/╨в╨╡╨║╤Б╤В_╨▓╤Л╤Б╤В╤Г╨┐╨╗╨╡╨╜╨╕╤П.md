# Текст выступления к презентации IRSbese

Здравствуйте. Наш проект называется IRSbese. Это учебный маркетплейс, который объединяет покупателей и продавцов.

Проблема, которую решает проект, — пользователю нужно быстро находить товары и сравнивать предложения, а продавцу — размещать свои товары и управлять ими. Поэтому мы создаём одну площадку с каталогом, поиском, корзиной и личными кабинетами.

Основные пользователи — покупатели и продавцы. Покупатель может зарегистрироваться по почте или телефону, найти товар, открыть карточку, добавить его в корзину и оформить заказ. После оформления заказ появляется в истории личного кабинета. Можно выбрать курьерскую доставку или самовывоз.

Продавец регистрируется с данными компании, добавляет товары, загружает изображения, редактирует описание и цену, а также может скрывать товары. Товары категории 18+ запрещены в текущей версии.

Для разработки используется Python и Flask. Данные учебного MVP хранятся в SQLite. Интерфейс сделан на HTML, CSS и JavaScript. Для запуска на сервере подготовлены Gunicorn и Nginx.

Отдельное внимание уделено безопасности: пароли хранятся в виде хэшей, формы защищены CSRF, а права доступа проверяются на сервере. Данные банковских карт сайт не собирает и не хранит. Интеграция ЮKassa подготовлена для тестового режима, но включается только после получения тестовых ключей.

Перед запуском необходимо провести полный прогон автоматических и ручных тестов, проверить адаптивность, нагрузку и настройки сервера. В итоге IRSbese представляет собой основу маркетплейса с основными пользовательскими сценариями и документацией для дальнейшего развития. Спасибо за внимание.
