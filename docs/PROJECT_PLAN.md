# План-график и оценка работ

## Потоки работ
1. Требования и проектирование: аудитория, сценарии, ограничения, бэклог.
2. UI: брендбук, шаблоны, каталог, карточка, кабинет, состояния ошибок.
3. Сервер: SQLite, учётные записи, корзина, заказы, кабинет продавца, рекомендации.
4. Оплата: адаптер ЮKassa, callback/webhook, идемпотентность; заблокировано до тестовых ключей.
5. QA: unit/integration, адаптивность, нагрузка, приёмка.
6. Релиз: README, Gunicorn, Nginx, резервные копии, демонстрация.

## Оценка
Оценки в часах находятся в листе «ЗАДАЧИ» актуального трекера. Они являются плановыми оценками команды, а не фактически затраченным временем. Фактические часы не проставлять без подтверждения исполнителей.

## Предлагаемые спринты
- Спринт 1: требования, схема БД, каркас UI, базовый каталог.
- Спринт 2: авторизация, профиль, корзина, заказ, продавец.
- Спринт 3: рекомендации, восстановление доступа, платёжный адаптер, security hardening.
- Спринт 4: тестирование, исправления, релизная подготовка и защита.

## Контрольные точки
Каждая задача принимается по артефакту и тесту. Внешние действия (создание магазина ЮKassa, PR, запись видео, реальный деплой) требуют соответствующих аккаунтов и доступа.
