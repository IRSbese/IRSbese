# Приоритизированный бэклог MVP

## P0 — обязательное ядро
- Каталог, поиск, фильтр категории, карточка товара.
- Регистрация/вход, профиль, история заказов.
- Корзина и серверный расчёт суммы.
- Создание заказа с проверкой остатков и сохранением позиций.
- Роли покупателя/продавца и проверка владельца данных.
- Кабинет продавца: создание, изменение, скрытие товара.
- CSRF, хэширование паролей, безопасная загрузка изображений, конфигурация через env.

## P1 — улучшение MVP
- Рекомендации на основе покупок и просмотров.
- Блоки «Похожие товары», «С этим товаром часто покупают», «Популярное», «Новинки».
- Выбор курьера/самовывоза.
- Восстановление пароля при настроенном SMTP.
- Тестовый платёж ЮKassa после выдачи тестовых ключей.

## P2 — после учебной защиты
- Реальная модерация продавцов и товаров.
- Интеграция служб доставки.
- PostgreSQL, Redis, очереди, объектное хранилище.
- Админ-панель, аудит действий, расширенная аналитика.
- Production monitoring, централизованные логи, полноценное нагрузочное тестирование.

## Зависимости
ЮKassa: решение заказчика → тестовый магазин → тестовые ключи → тестовые сценарии. Деплой: доступ к серверу и домену → HTTPS → резервные копии → smoke test.
