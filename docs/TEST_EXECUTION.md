# Отчёт о проверках

## Выполнено статически
- Python-файлы проходят `compileall`.
- Проверена структура SQLite schema и наличие миграций.
- Шаблоны проверяются на синтаксис Jinja при установленном Flask/Jinja.
- В репозитории нет файла `.env`; секреты читаются из переменных окружения.
- Для POST/PUT/PATCH/DELETE предусмотрена CSRF-проверка, кроме webhook ЮKassa.

## Автоматические тесты
Запуск: `python -m unittest discover -s tests -v`.

В текущей рабочей среде Flask/Werkzeug отсутствуют, а сетевой доступ к PyPI недоступен. Поэтому тестовый набор написан и статически проверен, но полноценный запуск тестов здесь не подтверждён.

## Ручные проверки, которые требуют запуска приложения
- Проверка в браузере на 390 px и 1280 px.
- Ручной заказ и проверка записи в личном кабинете.
- Ручная проверка тестового платежа успешной и неуспешной картой.
- Проверка webhook на реальном тестовом магазине ЮKassa.
- Проверка чистого окружения на отдельной машине.
- Нагрузочный прогон против работающего сервера.

Результаты этих действий не отмечать как пройденные до фактического выполнения.
