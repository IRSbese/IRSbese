# Предварительная смета IRSbese

Это оценка структуры затрат, а не коммерческое предложение. Реальные суммы зависят от выбранного VPS, трафика, тарифов и условий провайдеров.

| Статья | Периодичность | Как определить стоимость |
|---|---|---|
| VPS Ubuntu | Ежемесячно | Тариф с запасом CPU/RAM и диска под ожидаемую нагрузку |
| Домен | Ежегодно | Цена регистратора и продления |
| TLS-сертификат | Обычно бесплатно при Let's Encrypt | Учитывать время настройки и продления |
| Резервное хранилище | Ежемесячно | Объём БД, uploads и срок хранения копий |
| Почтовый сервис для восстановления доступа | По тарифу провайдера | Нужен после выбора механизма email |
| Комиссия платежного провайдера | С каждой операции | Уточнить в договоре ЮKassa; не фиксировать без тарифа |
| Мониторинг и логи | По тарифу/объёму | Можно начать с системных журналов и бесплатного мониторинга |

## Что нужно уточнить
- Ожидаемое число пользователей и одновременных запросов.
- Требуемый срок хранения резервных копий.
- Регион и параметры VPS.
- Нужен ли платный email-провайдер.
- Комиссии и договорные условия платёжного провайдера.

До получения этих данных конкретные денежные суммы не указываются, чтобы не выдавать догадки за утверждённый бюджет.
