# Заглушки изображений товаров и alt-тексты

В каталоге используются локальные SVG-заглушки из `app/static/img/products/`. Они являются иллюстрациями, а не фотографиями реальных товаров.

| Файл | Товар | Рекомендуемый alt |
|---|---|---|
| headphones.svg | Наушники беспроводные | Беспроводные наушники — иллюстрация товара |
| backpack.svg | Рюкзак городской | Городской рюкзак — иллюстрация товара |
| lamp.svg | Настольная лампа | Настольная лампа — иллюстрация товара |
| keyboard.svg | Клавиатура механическая | Механическая клавиатура — иллюстрация товара |
| mug.svg | Керамическая кружка | Керамическая кружка — иллюстрация товара |
| bag.svg | Сумка через плечо | Сумка через плечо — иллюстрация товара |

Для пользовательских загрузок `alt` формируется из названия товара. Перед коммерческим релизом заменить демонстрационные иллюстрации лицензированными фото и проверить точность описаний.
