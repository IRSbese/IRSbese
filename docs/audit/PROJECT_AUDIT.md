# Технический аудит IRSbese — итоговая сборка

## Состав
- Flask-приложение с маршрутами каталога, аккаунта, корзины, продавца и оплаты.
- SQLite-схема с пользователями, товарами, корзинами, заказами, позициями, просмотрами, платежами и токенами восстановления.
- Миграция старой схемы пользователей с сохранением ID и связей.
- HTML-шаблоны, CSS, JavaScript, локальные SVG-заглушки товаров.
- 23 автоматических теста `unittest`.
- README, требования, истории пользователей, бэклог, роли, риски, планирование, QA, релиз, презентация и UI-макеты.

## Статические проверки этой сборки
- 17 Python-файлов прошли AST parsing.
- `compileall` прошёл без ошибок.
- 20+ HTML/Jinja шаблонов успешно обработаны HTML parser.
- Все `url_for` ссылки шаблонов соответствуют объявленным endpoint; неразрешённых endpoint нет.
- Все POST-формы шаблонов содержат CSRF-токен.
- SQLite-схема успешно создаёт таблицы; миграция старой таблицы users проверена на сохранение связей.
- Bash-синтаксис deploy и backup скриптов проверяется отдельно.
- Архив проходит `zipfile.testzip()`.

## Не подтверждено
Flask/Werkzeug отсутствуют в текущем рабочем окружении; сетевой доступ к PyPI недоступен. Поэтому нельзя честно заявить, что приложение было запущено и 23 теста реально прошли. Результаты unittest должны быть получены в окружении с установленными requirements.

## Риски/ограничения
- ЮKassa требует тестовый магазин и ключи; флаг оплаты по умолчанию выключен.
- Восстановление пароля требует SMTP.
- Нет административной панели и полной ручной модерации; простая проверка 18+ не заменяет модератора.
- SQLite и локальные uploads подходят для учебного MVP, но не являются подтверждением готовности к высокой коммерческой нагрузке.
- Фактический VPS, DNS, HTTPS и production deploy не выполнялись.
