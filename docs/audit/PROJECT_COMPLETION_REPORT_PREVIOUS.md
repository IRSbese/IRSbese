# Отчёт по актуальной сводке IRSbese

Дата обработки: 24.11.2026

## Что выполнено в рамках этой сборки
- Обновлены статусы задач в исходном XLSX без изменения структуры листов.
- Для задач, подтверждённых кодом или созданными документами, добавлены пояснения в комментарии.
- Подготовлены документы: тест-план, 30 тест-кейсов, критерии приёмки, матрица ролей, реестр рисков, предварительная смета, план спринтов, протокол коммуникаций, шаблон журнала изменений, антикризисный план, план релиза и описания alt для товарных изображений.
- Исправлена настройка `SECRET_KEY`: ключ берётся только из переменной окружения; без ключа приложение не запускается вне тестового режима. Режим отладки остаётся выключенным по умолчанию и управляется `FLASK_DEBUG`.
- README дополнен инструкциями запуска и ссылками на рабочие документы.

## Статусы, которые нельзя честно поставить «Готово»
- T-008, T-042: требуется письменное решение заказчика по оплате и возрастным ограничениям; платежи остаются выключенными.
- T-054, T-064–T-066: необходим тестовый магазин и реальные тестовые ключи ЮKassa для проверки платежного цикла.
- T-043, T-067–T-073, T-099–T-103, T-110–T-115: требуется фактический запуск тестов, ручные проверки, скриншоты и результаты QA. В этой среде Flask/Werkzeug не установлены и нет доступа к PyPI, поэтому полноценный запуск приложения и тестов не подтверждён.
- T-049: подготовлены Gunicorn/systemd/Nginx, но кэширование и измерение нагрузки не выполнены.
- T-050, T-075, T-076: не предоставлены презентация, Pull Request и видеодемонстрация.
- T-082–T-103 и T-109: часть требований/макетов/функций (доставка, восстановление доступа, профиль, регистрация компании, управление товарами, модерация 18+, отдельные блоки рекомендаций и ошибки рядом с полями) ещё требует реализации или решения заказчика.
- T-115: скриншоты 390 px и 1280 px должны быть получены на работающем сайте.

## Важное уточнение
Статусы `Готово`, которые уже были в исходной сводке, в основном сохранены. Они не означают, что каждая такая задача была независимо перепроверена в рамках этой обработки. Новые статусы изменены только там, где удалось подтвердить результат кодом или документом.

## Проверки этой сборки
- Python-файлы проверены компиляцией и синтаксическим разбором.
- XLSX сохранён с исходными листами и структурой.
- ZIP-архив проекта проверен на целостность.
- Полный запуск Flask-приложения и автоматических тестов не подтверждён.
- Деплой на VPS не выполнялся.
