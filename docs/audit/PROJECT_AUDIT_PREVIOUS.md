# IRSbese — аудит обновлённой версии

Дата: 24.11.2026.

## Основа работы

Проект перестроен по исходному `README.md`, разделу «Что разработчику нужно реализовать», и сверён с командным трекером. Сохранены Python + Flask, существующие страницы, структура папок, логотипы и палитра брендбука.

## Реализованные направления

- SQLite: пользователи, товары, заказы, позиции заказа, сохранённые корзины, история просмотров и платежи.
- Регистрация, вход, выход, роли покупателя/продавца, хэширование паролей.
- CSRF-проверка для всех изменяющих запросов, кроме webhook; webhook перепроверяет платёж через API ЮKassa. Добавлены security headers и CSP.
- Сохранение корзины аккаунта в БД и объединение гостевой корзины при входе/регистрации.
- Создание заказа в транзакции с повторной проверкой остатков.
- Кабинет продавца; фотографии проверяются как изображения и пересохраняются в WebP.
- Персональные рекомендации на основе истории покупок и просмотров; fallback по популярности для новых пользователей.
- Обработчики и страницы ошибок 400, 403, 404, 413, 500.
- Подготовлен изолированный API-адаптер ЮKassa: создание платежа, возврат, webhook и сверка суммы/валюты/metadata.
- Оплата выключена по умолчанию из-за незакрытого требования T-008; T-042 отмечена заблокированной, не выполненной.
- Подготовлены Gunicorn, systemd, Nginx, ProxyFix, .env.example и скрипт резервного копирования; исходники доступны сервису только на чтение, запись разрешена для БД и загрузок.

## Проверки, выполненные в этой среде

- Python AST/compileall: 16 Python-файлов разобраны без синтаксических ошибок.
- Jinja2: все 20 HTML-шаблонов разобраны без синтаксических ошибок.
- SQLite: схема создаёт 8 таблиц; базовые вставки и внешние ключи проверены.
- Ссылки `url_for` в шаблонах сверены с маршрутами; неразрешённых endpoint-ссылок не найдено (кроме стандартного `static`).
- Полный Flask unittest-прогон не выполнен: в среде отсутствует Flask/Werkzeug, а установка зависимостей заблокирована отсутствием сетевого доступа к PyPI. На машине с доступом к пакетам выполнить `pip install -r requirements.txt` и `python -m unittest discover -s tests -v`.

## Осталось до релиза

1. Закрыть T-008: заказчик должен подтвердить оплату в первой версии и возрастные ограничения/категории товаров.
2. После согласования — выдать тестовые ключи ЮKassa и провести сквозной тест платежей.
3. Запустить Flask-тесты в окружении с зависимостями и провести ручную проверку на телефоне, планшете и ПК.
4. Выполнить нагрузочное и приёмочное тестирование.
5. Развернуть на VPS, настроить DNS/HTTPS и проверить домен.
6. Подготовить юридические страницы, модерацию, журналирование и операционные процедуры для публичного маркетплейса.

## Ограничения

Фактическое подключение к VPS не выполнялось. Пароль SSH не используется и не включён в архив. Из-за публикации пароля в переписке его следует сменить и перейти на SSH-ключ.
