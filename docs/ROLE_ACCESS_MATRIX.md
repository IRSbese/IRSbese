# Матрица ролей и прав доступа IRSbese

| Действие | Гость | Покупатель | Продавец |
|---|---:|---:|---:|
| Просмотр главной, каталога и карточек | Да | Да | Да |
| Добавление в гостевую корзину | Да | Да | Да |
| Оформление заказа | Нет | Да | Да, в покупательском сценарии |
| Просмотр истории заказов | Нет | Только свои | Только свои |
| Изменение собственного профиля | Нет | Да | Да |
| Доступ к кабинету продавца | Нет | Нет | Да |
| Добавление товара | Нет | Нет | Да |
| Изменение/скрытие товара | Нет | Нет | Только собственные товары |
| Просмотр публичных товаров | Активные разрешённые товары | Активные разрешённые товары | Активные разрешённые товары |
| Доступ к тестовым секретам оплаты | Нет | Нет | Нет |

Проверки выполняются на сервере. ID пользователя берётся из защищённой сессии, роль читается из БД. Запросы к заказам ограничиваются `user_id`, запросы на редактирование товаров — `seller_id`. Скрытие кнопки в интерфейсе не заменяет серверную проверку.

Отдельная роль администратора/модератора и административная панель в текущем MVP не реализованы. Перед коммерческим запуском нужно назначить модератора, определить проверку продавцов и добавить журнал действий.
