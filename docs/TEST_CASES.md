# Тест-кейсы IRSbese

Статусы ниже оставлены для заполнения после фактического запуска. Ожидаемый результат — критерий проверки.

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Поиск по названию | Открыть каталог, ввести существующее название | Показаны совпадающие активные товары |
| TC-02 | Пустой поиск | Ввести строку без совпадений | Показано пустое состояние, сервер не возвращает 500 |
| TC-03 | Фильтр категории | Выбрать категорию | Показаны товары выбранной категории |
| TC-04 | Неизвестный товар | Открыть `/product/999999` | HTTP 404 |
| TC-05 | Регистрация | Заполнить корректные данные | Аккаунт создан, пользователь авторизован |
| TC-06 | Дублирующий email | Повторить регистрацию с тем же email | Понятная ошибка, второй аккаунт не создан |
| TC-07 | Неверный пароль | Войти с неверным паролем | Вход отклонён, секреты не раскрываются |
| TC-08 | Хэш пароля | Проверить запись пользователя в БД | В БД нет исходного пароля |
| TC-09 | CSRF | Отправить POST без `_csrf` | Запрос отклонён с 400 |
| TC-10 | Доступ покупателя к продавцу | Войти покупателем и открыть `/seller` | Доступ запрещён |
| TC-11 | Добавление товара | Войти продавцом, заполнить форму | Товар связан с ID продавца |
| TC-12 | Чужой товар | Попытаться изменить товар другого продавца | Изменение недоступно |
| TC-13 | Неверный файл | Загрузить файл, не являющийся изображением | Файл отклонён с понятной ошибкой |
| TC-14 | Лимит файла | Загрузить файл больше 5 МБ | Запрос отклонён, HTTP 413 |
| TC-15 | Корзина | Добавить товар, изменить количество | Количество и сумма пересчитаны |
| TC-16 | Некорректное количество | Передать 0, отрицательное и текстовое значение | Значение отклонено или безопасно исправлено |
| TC-17 | Удаление из корзины | Удалить позицию | Позиция отсутствует в корзине |
| TC-18 | Пустой заказ | Открыть оформление с пустой корзиной | Создание заказа невозможно |
| TC-19 | Заказ | Оформить заказ с корректными данными | Заказ и позиции сохранены в БД |
| TC-20 | Остаток | Заказать больше доступного остатка | Заказ не создаётся, остаток не уходит ниже нуля |
| TC-21 | История | Войти владельцем заказа | Отображается собственный заказ |
| TC-22 | Чужая история | Открыть данные другого пользователя | Доступ к чужому заказу отсутствует |
| TC-23 | Рекомендации | Открыть главную авторизованным пользователем | Показаны доступные рекомендации |
| TC-24 | Оплата выключена | Оставить `PAYMENTS_ENABLED=0` | Платежный переход недоступен |
| TC-25 | Успешная оплата | В тестовой среде получить подтверждение ЮKassa | Заказ меняет статус только после проверки API |
| TC-26 | Повторный webhook | Отправить одно событие повторно | Повторная обработка не создаёт повторный платеж/заказ |
| TC-27 | Отмена оплаты | Подтвердить отмену тестового платежа | Платёж и заказ получают согласованный статус |
| TC-28 | Адаптивность | Проверить ширины 390/768/1280 px | Нет горизонтального переполнения и сломанных блоков |
| TC-29 | Ошибки | Открыть несуществующий URL и отправить плохие данные | Отображаются корректные страницы ошибок |
| TC-30 | Чистый запуск | Установить зависимости в чистой среде и запустить по README | Приложение стартует без ручных правок исходников |

**Фиксация результата:** для каждого кейса заполнить `Факт`, `Статус`, `Ссылка на скриншот/лог`, `Исполнитель`, `Дата`. Кейсы не считаются пройденными только на основании ожидаемого результата.
