# Реестр рисков проекта IRSbese

**Критерий успеха:** Выдержка большой нагруженности системы.  
**Стек и ключевые вводные:** Веб-приложение на Python (MVP 1), интеграция с ЮKassa (MVP 2), кабинет продавца (MVP 3).
