# UI-макеты IRSbese

В `mockups/` находятся статические адаптивные HTML-макеты ключевых экранов, собранные по палитре и шрифту брендбука. Это UI-концепты для сверки структуры и пользовательских состояний, а не скриншоты запущенного Flask-приложения и не исходные Figma-файлы. Открывайте HTML в браузере; ширина 390 px поддерживается медиазапросом.
